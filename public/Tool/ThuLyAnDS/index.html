Tải phần mềm

Nhấn nút dưới đây để mở thư mục Google Drive và tải bản Portable mới nhất.

MỞ THƯ MỤC TẢI PHẦN MỀM
Phiên bản hiện tại: ThuLyAnDS_Portable_v1.0.6

Lưu ý: Không chạy phần mềm trực tiếp trong file ZIP. Hãy giải nén toàn bộ vào một thư mục cục bộ, đọc file DOC_TRUOC_KHI_CHAY.txt, sau đó chạy KIEM_TRA_HE_THONG.bat và KHOI_DONG_UNG_DUNG.bat.

Cách cài đặt và sử dụng lần đầu

  1. Trong Google Drive, tải file ThuLyAnDS_Portable_v1.0.6.zip về máy.
  2. Giải nén toàn bộ vào thư mục như D:\ThuLyAnDS; không đặt trong Program Files, OneDrive hoặc ổ mạng.
  3. Chạy CHUAN_BI_LAN_DAU.bat nếu dùng Windows 10 hoặc cửa sổ phần mềm chưa mở được.
  4. Chạy KIEM_TRA_HE_THONG.bat, sau đó mở phần mềm bằng KHOI_DONG_UNG_DUNG.bat.
  5. Vào mục Cài đặt để nhập thông tin đơn vị, danh sách nhân sự và API key Gemini.
