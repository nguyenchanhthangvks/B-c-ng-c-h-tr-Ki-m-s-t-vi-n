Hướng Dẫn Quy Trình 4 Bước Sử Dụng AI Để Tóm Tắt Nội Dung Vụ Án / Vụ Việc Thành Sơ Đồ Tư Duy, Định Dạng Xmind Trực Quan Chỉ Trong 2 Phút

Giải pháp ứng dụng Trí tuệ nhân tạo (AI) giúp tóm tắt toàn bộ tình tiết phức tạp thành cấu trúc hình ảnh trực quan trên phần mềm Xmind.

BƯỚC 1

Tải Nội Dung Lên Gemini (hoặc Claude hoặc ChatGPT ...)

Truy cập AI, nhấn biểu tượng kẹp giấy để tải file hồ sơ (Word/PDF).

Hoặc copy-paste nội dung vụ án/vụ việc đã che thông tin cá nhân hoặc các thông tin liên quan đến bảo mật của tài liệu.

Kéo thả Cáo trạng/Hồ sơ vụ việc vào đây

BƯỚC 2

Yêu Cầu Tạo Mã Markdown

Lời khuyên

Hãy yêu cầu AI chỉ trả về từ khóa ngắn gọn và dùng các thẻ Markdown (#, ##, -) để phân cấp nhánh hợp lý cho Xmind.

Lưu ý: Chỉ viết nội dung tóm tắt, ngắn gọn bằng từ khóa để Xmind hiển thị đẹp mắt, không viết đoạn văn dài.

BƯỚC 3

Lưu Tệp Đuôi .md Với Notepad

Dán mã AI vừa trả về vào Notepad. Nhấn Ctrl + S. Tại ô Save as type chọn All Files (*.*) và đặt tên file là sodo.md. Nhớ chọn Encoding UTF-8 để không bị lỗi phông chữ tiếng Việt.

sodo.md - Notepad
File name:
sodo.md
Save as type:
All Files (*.*)
BƯỚC 4

Nhập Tệp Vào Xmind

Mở phần mềm Xmind, chọn File → Import → Markdown. Chọn file .md vừa lưu, sơ đồ sẽ tự động bung nở với đầy đủ cấu trúc logic đã phân tích.
