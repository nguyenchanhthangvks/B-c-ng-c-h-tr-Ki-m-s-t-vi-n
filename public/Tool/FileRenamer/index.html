Chuẩn hóa tên file - Tự động hóa

Giới thiệu

Công cụ tự động đổi tên file trong thư mục giúp bạn nhanh chóng quét và chuẩn hóa tên file hàng loạt. Công cụ phát hiện các file có tên chứa tiếng Việt có dấu, tên quá dài, hoặc chứa ký tự đặc biệt - và đề xuất tên mới chuẩn hóa để bạn xem xét trước khi thực thi.

Điểm nổi bật: Giao diện trực quan - Xem trước kết quả - Chọn file muốn đổi - Thực thi chính xác!

Cách sử dụng

  • Bước 1: Tải FileRenamer.zip và giải nén toàn bộ vào một thư mục
  • Bước 2: Mở thư mục FileRenamerPortable, chạy FileRenamerPortable.exe rồi chọn thư mục cha chứa file cần đổi tên
  • Bước 3: Bấm "Quét ngay" để xem danh sách file có vấn đề (tên cũ → tên đề xuất)
  • Bước 4: Tích chọn file muốn đổi tên (mặc định chọn tất cả)
  • Bước 5: Bấm "Thực thi đổi tên" để áp dụng đổi tên cho các file đã chọn

Lưu ý: Không chạy tệp trực tiếp khi còn nằm trong ZIP. Hãy giải nén đầy đủ rồi mở FileRenamerPortable.exe. Công cụ sẽ tự động mở giao diện trong trình duyệt cục bộ; dữ liệu vẫn chỉ được xử lý trên máy tính.
