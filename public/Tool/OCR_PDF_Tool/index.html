Công cụ chuyển đổi PDF thành chữ giúp bạn trích xuất văn bản từ file PDF dạng ảnh quét (scan) sang các định dạng có thể chỉnh sửa: Markdown (.md), Word (.docx) và văn bản (.txt).

Công cụ sử dụng engine Tesseract OCR (phiên bản 5) kết hợp với PyMuPDF để xử lý PDF và Pillow để tiền xử lý ảnh, hỗ trợ nhận dạng tiếng Việt và tiếng Anh với độ chính xác cao.

Điểm nổi bật: Hoạt động hoàn toàn offline — Không cần Internet — Nhận dạng tiếng Việt — Xuất Markdown, DOCX, TXT — Giao diện kéo thả trực quan!

Cách sử dụng

  • Bước 1: Tải file OCR_PDF_Tool.zip về máy và giải nén vào một thư mục
  • Bước 2: Mở thư mục OCR_PDF_Tool rồi nhấp đúp vào OCR_PDF_Tool.exe
  • Bước 3: Trình duyệt tự mở giao diện web. Kéo thả file PDF vào vùng upload (có thể chọn nhiều file cùng lúc)
  • Bước 4: Chọn ngôn ngữ (tiếng Việt / tiếng Anh) và định dạng đầu ra mong muốn (Markdown / DOCX / TXT)
  • Bước 5: Nhấn "OCR 1 FILE ĐƠN" (xử lý từng file) hoặc "OCR HÀNG LOẠT" (xử lý nhiều file)
  • Bước 6: Xem kết quả hiển thị theo từng trang. Có thể copy trực tiếp hoặc tải về file kết quả.

Mẹo sử dụng: Công cụ chạy hoàn toàn offline, không cần Internet. Với file PDF nhiều trang, kết quả được hiển thị riêng biệt cho từng trang, có phân cách rõ ràng. Ở chế độ hàng loạt, tất cả kết quả được đóng gói vào file ZIP để tiện tải về. Không cần cài đặt Python, Tesseract hay bất kỳ thư viện nào!

Công nghệ sử dụng

Engine OCR: Tesseract OCR 5 + Leptonica — Nhận dạng ký tự quang học từ ảnh

Xử lý PDF: PyMuPDF (fitz) — Trích xuất từng trang PDF thành ảnh để OCR

Xử lý ảnh: Pillow (PIL) — Tiền xử lý ảnh trước khi nhận dạng

Ngôn ngữ hỗ trợ: Tiếng Việt (vie) + Tiếng Anh (eng) — Có thể mở rộng thêm

Giao diện: Flask + HTML/CSS/JS — Giao diện web kéo thả, chạy trên localhost

Định dạng xuất: Markdown (.md) + DOCX (.docx) + TXT (.txt)
